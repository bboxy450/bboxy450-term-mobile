# bboxy450-term-mobile

The bboxy450 phone app for iOS and Android. It is a small addition to the
[bboxy450-term](https://github.com/bboxy450/bboxy450-term) desktop cockpit:
it shows the swarm and answers seats' questions on the move, even with the
laptop closed.

It is drawn by the same Rust UI kit as the desktop (`bbt-ui`, `bbt-render`
on wgpu), which comes from `vendor/bboxy450-term`.

The specification is `specs/mobile` in the bboxy450-term knowledge base
(`.bboxy/specs/mobile.den`), together with the decision
`d1794292861627536-remote-nodes-round-4-mobile-both-platforms`.

Run `make help`.
